# Control Pyme Beta

Beta pública de Control Pyme para Pymes chilenas.

Incluye diagnóstico conversacional, dashboard financiero, caja proyectada, alertas, cobranza, reportes y Legal Pyme.

## Streamlit Cloud
- Archivo principal: `app.py`
- Python recomendado: 3.12
- Dependencias: `requirements.txt`
- Los secretos deben configurarse en Streamlit Cloud y nunca almacenarse en GitHub.

La base demo local se crea al iniciar cuando corresponde. Los leads persistentes deben almacenarse en Supabase.
